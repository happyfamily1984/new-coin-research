코인 검증기 개인정보처리방침

시행일: 2026년 11월 25일 · 앱: 코인 검증기 (com.happyfamily.coinverifier)

코인 검증기(이하 "앱")는 이용자의 개인정보를 중요하게 생각하며, 「개인정보 보호법」 등 관련 법령을 준수합니다. 본 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

1. 수집하는 개인정보

앱은 회원가입이나 로그인 기능이 없으며, 이름·연락처·이메일·위치·기기 식별자 등 개인정보를 수집하거나 개발자 서버로 전송하지 않습니다. 앱에는 광고나 분석(트래킹) 도구가 포함되어 있지 않습니다.

2. 기기 안에만 저장되는 정보

다음 정보는 이용자의 기기 내부 저장소에만 저장되며, 개발자는 이 정보에 접근할 수 없습니다.

  • 분석한 프로젝트 목록, 우선순위, 메모, 참여 체크리스트
  • 이용자가 직접 입력한 Gemini API 키, CoinGecko API 키 및 앱 설정

앱을 삭제하거나 앱 데이터를 지우면 위 정보는 모두 삭제됩니다. 이용자는 설정의 [내보내기] 기능으로 직접 백업할 수 있습니다.

3. 외부 서비스로 전송되는 정보

분석 기능을 제공하기 위해, 이용자가 검색한 코인 프로젝트 이름·심볼·컨트랙트 주소 등 공개 정보가 아래 외부 서비스에 조회 요청으로 전송됩니다. 개인정보는 포함되지 않습니다.

Gemini API는 이용자가 설정에서 본인의 API 키를 등록한 경우에만 사용됩니다. 해당 요청은 Google의 약관과 개인정보처리방침이 적용되며, 무료 등급에서는 입력 내용이 Google 서비스 개선에 활용될 수 있습니다. 각 외부 서비스의 정보 처리는 해당 서비스의 개인정보처리방침을 따릅니다.

4. 개인정보의 제3자 제공 및 위탁

앱은 개인정보를 수집하지 않으므로 제3자에게 제공하거나 처리를 위탁하지 않습니다.

5. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 수집하지 않습니다.

6. 투자 관련 고지

앱이 제공하는 점수·분석·전략은 공개 데이터와 자동 규칙(및 선택 시 AI)으로 생성된 참고 정보이며, 투자 권유나 금융 자문이 아닙니다. 투자 판단과 그 결과에 대한 책임은 이용자에게 있습니다.

7. 이용자의 권리

이용자는 앱 내 삭제 기능 또는 앱 데이터 삭제를 통해 언제든지 기기에 저장된 모든 정보를 삭제할 수 있습니다.
