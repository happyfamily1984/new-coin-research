### 자세한 설명 (4000자 이내)

```
새로 나온 코인 프로젝트, 참여하기 전에 먼저 검증하세요.

코인 검증기는 프로젝트 이름만 입력하면 여러 공개 데이터를 교차 확인해
신뢰도와 성장 가능성을 점수로 보여 주고, 일반인이 참여해 수익을 낼 수 있는
방법까지 쉬운 말로 정리해 주는 코인 프로젝트 분석 앱입니다.

■ 한 번에 보는 프로젝트 리포트
· 프로젝트 개요와 카테고리 (영어 정보는 한국어로 자동 번역)
· 신뢰도 점수 / 가능성 점수와 점수 근거
· 투자자·펀딩 라운드, 티어1 투자사 표시
· 시가총액·거래량·7일 시세 그래프, 유통 비율

■ 프로젝트 유형 & 참여 방식 자동 분류
· 유형: 노드형, 디파이, NFT, 게임파이, 커뮤니티·인플루언서형, 밈코인, AI, DePIN, RWA, 에어드랍형, 런치패드형, 다단계 의심형 등
· 참여 방식: 토큰 구매, 노드 구매·운영, NFT 민팅, 테스트넷·포인트 활동, SNS 참여·홍보, 스테이킹, 유동성 공급, 런치패드 청약 등

■ 초보자도 따라 하는 참여 전략
· "이게 뭔가요? / 어떻게 돈을 버나요? / 준비물 / 따라 하기 / 숫자 예시 / 주의할 점" 순서로 설명
· 단계별 체크리스트로 내 진행 상황 관리
· 수익 계산기: 토큰 수익률, 노드 원금 회수 기간, 에어드랍 기대값

■ 온체인 분석
· 허니팟(매도 불가), 추가 발행, 잔고 조작 권한, 거래세 등 토큰 보안 점검
· 상위 홀더 집중도, DEX 유동성과 매수·매도 건수, TVL
· 공식 컨트랙트 주소 복사로 가짜 토큰 구별

■ 거래소 상장 현황
· 업비트·빗썸 상장 여부와 유의 종목·주의 신호
· 바이낸스·코인베이스·OKX·바이비트·Gate 상장 여부
· 전체 상장 마켓과 거래량

■ 저장·우선순위·업데이트
· 분석한 프로젝트는 목록에 자동 저장
· 별점 우선순위, 드래그로 순서 변경, 유형·참여방식 필터
· [업데이트] 한 번으로 최신 데이터 반영, 점수·가격·신규 상장 변경점 알림
· 프로젝트 2~3개 나란히 비교

■ AI 웹 심층 조사 (선택)
· 무료 Gemini API 키를 등록하면 Google 검색으로 최신 뉴스, 토크노믹스, 언락 일정, 에어드랍 조건, 상장 소식까지 조사
· 키를 여러 개 등록하면 한도가 찬 키는 건너뛰고 자동 전환

■ 안전 기능
· 스캠 자가진단 체크리스트, 코인 사기 예방 가이드
· 다단계·러그풀·피싱 위험 신호 자동 감지

※ 본 앱은 투자 정보를 제공하는 참고용 도구이며, 투자 권유나 금융 자문이 아닙니다.
※ 코인 매매·보관 기능은 없으며, 투자 판단과 책임은 이용자에게 있습니다.
※ 회원가입 없이 사용하며, 분석 기록은 기기 안에만 저장됩니다.
```
